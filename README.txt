REV WEAR — COMING SOON WEBSITE

1. Place your exact Facebook cover photo in this folder and name it: facebook-banner.jpg
   (If your image is PNG, export or save a JPG copy.)
2. Upload index.html, rev-logo.png, and facebook-banner.jpg to the ROOT of your public GitHub repository.
3. On GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Test the github.io URL before connecting revwear.uk.
5. For your GoDaddy domain, set the custom domain in GitHub Pages and update ONLY the web-related DNS records. Do not delete Microsoft 365 MX, TXT, CNAME or other email records.

The page works without facebook-banner.jpg but uses a charcoal fallback background until you add it.
Contact email: info@revwear.uk (ensure the mailbox/alias exists before publishing).
Animations: IN PROGRESS dots, loading line, subtle background zoom. Responsive and reduced-motion accessible.
